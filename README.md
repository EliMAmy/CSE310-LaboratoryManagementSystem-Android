# Overview

The first part of this project was about an application will allow users to record  and manage data of laboratory, including information such as the experiment name, date, temperature, pH, time, and results.First I developed the basic functionality using Kotlin.Then I created and Android app with user-friendly interface.
This Laboratory and Research Management System is an Android mobile application designed to help users manage laboratory experiment information in an organized way. The application allows users to add, view, search, update, and delete experiment records. Each experiment can include information such as its name, description, date, temperature, pH, treatment time, and results.
I am creating this software to improve my skills in Kotlin and Android application development. This project allows me to practice transforming a console-based program into a mobile application with a user-friendly interface. It also helps me learn how to organize an Android project, create different screens, navigate between screens, and manage data using Kotlin.
The application is being developed as part of a larger learning process. The first stage focused on developing the laboratory management functionality using Kotlin. In this stage, I am adapting that functionality into an Android application. In a future stage, I plan to connect the application to Firebase Cloud Firestore so that experiment data can be stored and accessed from the cloud.

# Development Environment

I developed this software using Android Studio as the integrated development environment (IDE). The application uses Jetpack Compose to create the user interface and Android Navigation to move between different screens.
The programming language used for this project is Kotlin. Kotlin is used to implement the application logic, manage experiment data, and connect the different parts of the Android application.
The main tools and technologies used in this project include:

- Android Studio
- Kotlin
- Jetpack Compose
- Android Navigation
- Git and GitHub
